# Contributing to Parallax

Thanks for helping out. Fork the repo, create a branch off `main` and open a pull request when your change is ready.

## Local setup

Install dependencies with `npm install`. Run `npm run web` to preview the site in a browser and `npm start` to open the desktop app. Check both before opening a pull request, since they share the same code in `src`.

## Guidelines

Keep the site free of a build step so it can be hosted as plain static files. Put content changes in `src/data.js` and keep rendering logic in `src/app.js`. Perspective labels are editorial examples, so any new story needs a framing note that explains its label. Commit messages should be a single line.

## Reporting issues

Open a GitHub issue with steps to reproduce, the platform you were on and whether it happened on the web, the desktop app or both.
